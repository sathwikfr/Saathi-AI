# Emergency phrases to review (native speakers)

Saathi's code-level safety net (`src/lib/safety.ts`) raises a level-4 alert when a parent says one of these.
A missed phrase means a missed emergency, so please check each language for:

1. **Wrong or odd phrases** (remove or fix them).
2. **Missing everyday ways to say it** (chest pain, can't breathe, fell down, unconscious, heart attack, "help", ambulance), including spellings and the way the words are written in Roman letters when people type on WhatsApp.
3. **Common negations** that must NOT trigger (for example "no chest pain").

Send corrections back and they are added to `EMERGENCY_TERMS`. Last generated 2026-10-05.
